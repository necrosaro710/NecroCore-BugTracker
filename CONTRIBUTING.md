# Contributing

Issues and pull requests are welcome. Please describe your BfA 8.3.7 core fork/version, steps to reproduce, expected behavior, actual behavior, and any **redacted** relevant logs. Avoid posting real account information, credentials, host IPs, player names, or entire private ticket databases.

Bridge changes should include a reproducible core compatibility test; dashboard changes should include Python test coverage. Test updates on a separate server before proposing a production change. Maintenance is best-effort and response times are not guaranteed.
